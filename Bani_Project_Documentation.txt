Bani 프로젝트 문서
====================

이 문서는 Bani 프로젝트의 기능 명세, 시스템 아키텍처, 데이터베이스 스키마를 포함합니다.

---

## **1. Bani 프로젝트 기능 명세서**

### **1.1. 프로젝트 개요**

Bani 프로젝트는 대학생 및 교내 구성원을 위한 커뮤니티 포털 서비스입니다. 사용자들은 게시판을 통해 소통하고, 중고 물품을 거래하며, 실시간 채팅으로 교류할 수 있습니다. 또한 식단, 날씨, 뉴스 등 학교생활에 유용한 편의 정보를 제공하여 활발한 커뮤니티 환경 조성을 목표로 합니다.

### **1.2. 핵심 시스템**

#### **1.2.1. 사용자 시스템 (`users` 앱)**

*   **목적**: 웹사이트의 모든 사용자를 관리하고 인증 및 프로필 정보를 처리합니다.
*   **주요 데이터 (모델)**:
    *   `User`: Django의 기본 User 모델을 확장하여 `닉네임(nickname)`, `성별(gender)`, `지역(region)`, `평점(rating)`, `프로필 이미지(profile_image)` 등 추가 정보를 관리합니다.
*   **주요 기능**:
    *   회원가입: 아이디, 비밀번호, 이메일, 닉네임 등을 입력하여 새로운 계정을 생성합니다.
    *   로그인/로그아웃: 시스템 접근을 위한 인증을 처리합니다.
    *   프로필 수정: 사용자는 자신의 닉네임, 지역, 프로필 이미지 등 개인 정보를 수정할 수 있습니다.
    *   비밀번호 찾기/재설정: 아이디와 이메일 인증을 통해 비밀번호를 재설정할 수 있습니다.
    *   아이디 중복 확인: 회원가입 시 실시간으로 아이디 중복 여부를 확인합니다.

### **1.3. 주요 기능**

#### **1.3.1. 게시판 (`board` 앱)**

*   **목적**: 사용자들이 자유롭게 글을 작성하고 소통할 수 있는 커뮤니티 게시판 기능을 제공합니다.
*   **주요 데이터 (모델)**:
    *   `Post`: 게시글의 제목, 내용, 작성자, 작성일, 조회수, 공지 여부 등을 저장합니다.
    *   `Comment`: 게시글에 달린 댓글 정보를 저장하며, 대댓글(계층형) 기능을 지원합니다.
    *   `Category`: '자유게시판', '공지사항' 등 게시판의 종류를 구분합니다.
*   **주요 기능**:
    *   게시글 목록 조회: 전체 게시글을 최신순으로 보여주며, 공지글은 상단에 고정됩니다.
    *   게시글 작성/수정/삭제: 로그인한 사용자는 게시글을 작성하고, 자신의 글을 수정하거나 삭제할 수 있습니다.
    *   게시글 상세 조회: 게시글의 전체 내용과 댓글 목록을 보여주며, 조회 시 조회수가 1 증가합니다.
    *   댓글 작성/수정/삭제: 게시글 상세 페이지에서 댓글을 작성하고, 자신의 댓글을 수정하거나 삭제할 수 있습니다.

#### **1.3.2. 중고거래 (`trade` 앱)**

*   **목적**: 사용자들이 중고 물품을 등록하고 판매 또는 구매할 수 있는 마켓플레이스를 제공합니다.
*   **주요 데이터 (모델)**:
    *   `Product`: 판매 물품의 제목, 상세 설명, 가격, 이미지, 작성자, 조회수 등의 정보를 저장합니다. `wishlisted_by` 필드를 통해 '찜하기' 기능을 구현합니다.
*   **주요 기능**:
    *   물품 목록 조회: 등록된 모든 물품을 보여주며, 검색 및 정렬(최신순/과거순) 기능을 제공합니다.
    *   물품 등록/수정/삭제: 로그인한 사용자는 판매할 물품을 등록하고, 자신의 물품 정보를 수정하거나 삭제할 수 있습니다.
    *   물품 상세 조회: 물품의 상세 정보와 이미지를 보여주며, 조회 시 조회수가 1 증가합니다.
    *   찜하기 (Wishlist): 관심 있는 물품을 자신의 찜 목록에 추가하거나 제거할 수 있습니다.
    *   거래 채팅 시작: 물품 판매자와 1:1 실시간 채팅을 시작하여 거래를 조율할 수 있습니다.

#### **1.3.3. 실시간 채팅 (`message` 앱)**

*   **목적**: 사용자 간의 1:1 실시간 소통을 위한 채팅 기능을 제공합니다. (Django Channels 기반)
*   **주요 데이터 (모델)**:
    *   `ChatRoom`: 두 사용자 간의 고유한 채팅방 정보를 저장합니다.
    *   `Message`: 채팅방에서 주고받은 메시지의 내용, 발신자, 시간 등을 기록합니다.
*   **주요 기능**:
    *   1:1 채팅: 두 사용자 간에 실시간으로 메시지를 주고받을 수 있습니다.
    *   채팅 기록 조회: 채팅방에 입장하면 이전 대화 내용 50개를 자동으로 불러옵니다.
    *   실시간 알림: 채팅방에 있지 않아도 상대방으로부터 새로운 메시지가 오면 알림을 받습니다.

#### **1.3.4. 마이페이지 (`mypage` 앱)**

*   **목적**: 로그인한 사용자의 모든 활동 내역을 한곳에서 모아보고 관리할 수 있는 개인화된 페이지를 제공합니다.
*   **주요 기능**:
    *   내 활동 조회: 자신이 작성한 게시글/댓글, 등록한 판매 물품, 찜한 물품 목록을 확인합니다.
    *   프로필 정보 확인 및 수정: 자신의 프로필 정보를 확인하고, 수정 페이지로 이동할 수 있습니다.

### **1.4. 캠퍼스 생활 정보**

#### **1.4.1. 학식 메뉴 (`meal_plans` 앱)**

*   **목적**: 아산캠퍼스와 영동캠퍼스의 주간 학생 식당 메뉴 정보를 제공합니다.
*   **주요 데이터 (모델)**:
    *   `DailyMeal`: 특정 날짜, 캠퍼스, 식사 종류(중식/석식)에 해당하는 메뉴 정보를 저장합니다.
*   **주요 기능**:
    *   주간 식단 조회, 캠퍼스 선택 기능, 식단 관리(교직원용) 기능을 제공합니다.

#### **1.4.2. 랜덤 매칭 (`dating` 앱)**

*   **목적**: 재미를 위한 기능으로, 버튼을 누르면 이성 사용자를 랜덤으로 한 명 추천해 줍니다.
*   **주요 기능**:
    *   사용자가 '매칭' 버튼을 누르면, 자신을 제외한 이성 사용자 중 한 명의 프로필을 랜덤으로 보여줍니다. 일회성 기능입니다.

### **1.5. 기타 정보 서비스**

#### **1.5.1. 뉴스 (`news` 앱)**

*   **목적**: 외부 NewsAPI를 활용하여 최신 뉴스를 사용자에게 보여줍니다.
*   **주요 기능**:
    *   `newsapi.org`에서 한국어 기사를 인기도순으로 가져와 목록 형태로 보여줍니다.

#### **1.5.2. 날씨 (`weather` 앱)**

*   **목적**: 외부 OpenWeatherMap API를 활용하여 주요 도시의 날씨 정보를 제공합니다.
*   **주요 기능**:
    *   주요 도시들의 현재 날씨 정보를 카드 형태로 보여줍니다. 모든 데이터는 클라이언트 측에서 직접 API를 호출하여 처리합니다.

## **2. 시스템 아키텍처 (System Architecture)**

Bani 프로젝트는 전통적인 모놀리식(Monolithic) 웹 애플리케이션 아키텍처를 기반으로 합니다.

*   **프론트엔드 (Frontend)**: Django 템플릿 엔진을 통한 서버 사이드 렌더링(SSR)을 기본으로 하며, JavaScript(날씨, 채팅, AJAX)를 통해 동적인 기능을 구현합니다. UI는 Bootstrap 프레임워크를 사용합니다.

*   **백엔드 (Backend)**: Python 기반의 Django 프레임워크로 개발되었습니다. 기능별로 앱을 분리하여 모듈성을 높였고, Django ORM을 통해 데이터베이스와 상호작용합니다. 실시간 채팅은 Django Channels를 통해 WebSocket으로 구현했습니다.

*   **데이터베이스 (Database)**: Django가 지원하는 관계형 데이터베이스(RDBMS)를 사용합니다.

*   **외부 서비스 (External Services)**: News API (`newsapi.org`)와 OpenWeatherMap API (`openweathermap.org`)와 연동하여 뉴스 및 날씨 정보를 제공합니다.

## **3. 데이터베이스 스키마 (Database Schema)**

프로젝트의 주요 데이터 모델과 그 관계는 다음과 같습니다.

*   **`User`**: 시스템의 중심 모델로, 모든 사용자 정보를 담습니다.

*   **`Post`**: `User`에 1:N 관계로 연결됩니다.

*   **`Comment`**: `User`와 `Post`에 각각 1:N 관계로 연결되며, 대댓글을 위해 자신을 1:N 관계로 참조합니다.

*   **`Product`**: `User`와 `author`로서 1:N 관계를, `wishlisted_by`(찜하기)로서 M:N 관계를 가집니다.

*   **`ChatRoom`**: 채팅방 정보를 담는 독립적인 모델입니다.

*   **`Message`**: `ChatRoom`과 `User`(`sender`)에 각각 1:N 관계로 연결됩니다.

*   **`DailyMeal`**: 다른 모델과 직접적인 관계가 없는 독립적인 식단 정보 모델입니다.

### **관계 요약**

*   **1:N (일대다)**: `User`-`Post`, `User`-`Comment`, `User`-`Product`, `Post`-`Comment`, `ChatRoom`-`Message`, `User`-`Message`
*   **M:N (다대다)**: `User`-`Product` (찜하기 기능)
*   **Self-referencing**: `Comment` (대댓글)
