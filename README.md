## 1. 프로젝트 소개 (Project Overview)
> **"대학 생활의 모든 것을 하나로 담은, 캠퍼스 라이프 올인원 플랫폼"**

본 서비스는 학생들에게 꼭 필요한 정보와 소통 창구를 제공하는 **종합 커뮤니티 웹사이트**입니다. 정보 공유를 위한 게시판과 학교 식단표, 학생 간의 안전한 중고거래 기능을 기본으로 제공합니다.

특히 단순한 게시판 기능을 넘어, **WebSocket 기술**을 도입하여 **실시간 1:1 채팅**과 **즉각적인 알림 서비스**를 구현함으로써 사용자 간의 소통 속도를 획기적으로 높였습니다. 또한, 캠퍼스 내 자연스러운 만남을 위한 데이트(매칭) 기능을 더해 서비스의 재미와 활용도를 극대화했습니다.

## 2. 주요 기능 (Key Features)

### 📋 커뮤니티 & 라이프
* **자유 게시판:** 학생 간 정보 공유 및 소통
* **학교 식단표:** 실시간 학식 메뉴 조회
* **생활 편의 (API):**
    * **실시간 날씨:** 위치 기반 캠퍼스 날씨 정보 (OpenWeatherMap API)
    * **뉴스 피드:** 주요 뉴스 및 캠퍼스 이슈 제공 (News API)

### 🛒 마켓 플레이스
* **중고거래:** 교내 안전 거래 시스템 구축
* **이미지 최적화:** 대용량 사진 업로드 시 자동 압축(Resizing) 처리

### ⚡ 실시간 인터랙션 (WebSocket)
* **실시간 채팅:** 끊김 없는 1:1 대화 기능
* **즉시 알림:** 게시글 댓글 및 채팅 수신 시 실시간 알림(Notification) 전송

### ❤️ 소셜 네트워크
* **캠퍼스 데이트:** 랜덤 매칭 및 데이트 신청 기능

## 4. 트러블 슈팅 및 기술적 성장 (Troubleshooting)

### ① 웹소켓 (WebSocket) 도입
* **문제:** 실시간 통신을 위한 웹소켓의 개념과 비동기 로직 처리에 어려움을 겪음.
* **해결:** Gemini를 활용해 통신 구조를 집중 학습하고, 기존 동기식 코드와 분리하여 채팅 및 알림 시스템을 성공적으로 구현함.

### ② Git 협업과 Merge 충돌 해결
* **문제:** 팀원 동시 작업 시 빈번한 코드 충돌(Conflict) 발생.
* **해결:**
    * **브랜치 전략:** 기능 단위로 브랜치를 철저히 분리.
    * **워크플로우:** "Pull 먼저, Push 나중에" 규칙 확립 및 `.gitignore` 설정 강화.

### ③ Django ORM 적응
* **문제:** SQL 쿼리문에 익숙하여 객체 지향적인 ORM 방식 적응에 시간 소요.
* **해결:** 단순 기능 구현을 넘어, 효율적인 데이터 조회를 위해 코드를 리팩토링하며 ORM의 생산성을 체득함.

### ④ 대용량 이미지 및 정적 파일 최적화
* **문제:** 고화질 이미지 대량 업로드 시 서버 스토리지 부족 및 속도 저하 우려.
* **해결:**
    * **이미지 압축:** 업로드 시 자동으로 용량을 줄이는 리사이징(Resizing) 로직 구현.
    * **데이터 무결성:** 게시글 삭제 시 연결된 이미지도 스토리지에서 즉시 삭제되도록 처리.
    * **구조화:** CSS/JS 정적 파일을 별도 관리하여 유지보수성 향상.

### ⑤ 외부 API 데이터 연동 (날씨/뉴스)
* **문제:** 외부 API의 복잡한 JSON 데이터를 파싱하여 화면에 출력하는 과정에서 어려움 발생.
* **해결:**
    * `requests` 라이브러리를 통해 안정적으로 데이터를 호출.
    * JSON 데이터를 딕셔너리로 변환 후 필요한 정보만 추출하여 템플릿에 적용.
    * API Key를 환경 변수로 분리하여 보안성 강화.

## 5. 팀원별 역할 분담 (Team Roles)

### 🧑‍💻 이민규 (팀장 / 백엔드 & DevOps)
* **핵심 기능 구현 (WebSocket):** Django Channels를 활용한 실시간 1:1 채팅 및 알림 시스템 구축.
* **서버 인프라 구축 (DevOps):** AWS EC2(Ubuntu) 서버 환경 세팅 및 AWS RDS(MySQL) 데이터베이스 연동/배포 총괄.
* **형상 관리 (Git Master):** Git 브랜치 전략 수립, Merge 충돌 해결 및 `.gitignore` 등 협업 환경 세팅.
* **리소스 최적화:** 이미지 업로드 시 리사이징(압축) 로직 구현 및 정적 파일(Static/Media) 관리 자동화.

### 🧑‍💻 김기원 (프론트엔드 리드 / API 연동)
* **커뮤니티 기능 (CRUD):** 게시판(자유/정보) 및 중고장터의 게시글 작성, 수정, 삭제, 조회 기본 로직 구현.
* **UI/UX 디자인:** Bootstrap을 활용한 반응형 웹 페이지 레이아웃 설계 및 CSS 스타일링.
* **학교 정보 서비스:** 학교 식단표 크롤링/데이터 시각화 및 프론트엔드 템플릿(HTML) 구조화.
* **사용자 경험 개선:** 직관적인 네비게이션 바(Nav-bar) 구성 및 모바일 뷰 최적화 작업.

### 🧑‍💻 김승식 (백엔드 코어 / 비즈니스 로직)
* **외부 데이터 연동:** OpenWeatherMap(날씨), News API 연동 및 데이터 파싱 처리를 통한 정보 제공 기능 구현.
* **회원 관리 시스템:** Django Auth를 이용한 회원가입, 로그인/로그아웃, 비밀번호 찾기 기능 구현.
* **매칭 알고리즘:** 캠퍼스 데이트(매칭) 기능의 랜덤 매칭 로직 설계 및 데이터베이스 모델링(ERD) 설계.
* **검색 및 필터:** 게시글 검색 기능 및 카테고리별 필터링 기능 구현.
